# QGIS plugin compute environment, CUDA build — the GPU twin of plugin.txt.
#
# The installer picks this file over plugin.txt when nvidia-smi reports a
# usable NVIDIA driver on Linux/Windows x86_64 (plugin_utils/gpu_probe.py).
# Everything else about the environment is identical; only the inference
# runtime changes.
#
# MUST NOT BE COMBINED WITH base.txt, plugin.txt, ci.txt OR gpu.txt.
# onnxruntime and onnxruntime-gpu both provide the `onnxruntime` module, and
# pip will happily leave both installed — the loser's shared libraries then
# shadow the winner's and imports fail in ways that look like a broken CUDA
# install. plugin_utils/installer.py uninstalls the other one before pip runs;
# that is not belt-and-braces, it is the documented requirement.
#
# Hence `-r geo.txt` rather than `-r base.txt`: base.txt pins plain
# onnxruntime. The notebook/plotting extras base.txt also carries (ipykernel,
# matplotlib) are deliberately omitted for the same reason gpu.txt omits them
# — nothing on the compute path imports them.
-r geo.txt

# The [cuda,cudnn] extras pull the CUDA userspace in as nvidia-*-cu12 wheels
# (cuBLAS, cuDNN, cuFFT, cuRAND, nvrtc, cuda_runtime, nvJitLink), so the host
# needs an NVIDIA DRIVER and nothing else — no system CUDA toolkit, and no
# LD_LIBRARY_PATH: onnxruntime >= 1.26 preloads the wheel libraries itself.
# Measured cost: about 2.4 GB on disk. Measured benefit on an RTX 4080 SUPER
# with the 512x512 Spruce_Deadwood fp16 model: 12.4 ms per tile on
# CUDAExecutionProvider against 5265.7 ms on CPUExecutionProvider.
#
# VERSION PINNING IS DELIBERATE AND HARDWARE-DEPENDENT (same warning as
# gpu.txt). onnxruntime-gpu 1.27 moved its extras to CUDA 13 (nvidia-*-cu13)
# and fails at import with `ImportError: libcudart.so.13` on a cu12 machine;
# the ceiling below keeps the resolver on the cu12-era 1.26 line, which is
# what was verified end to end. Raise it only after re-running the provider
# check in docker/gpu/README.md on the target hardware. Blackwell (sm_120) in
# particular needs a recent CUDA — verify, do not assume.
onnxruntime-gpu[cuda,cudnn]<1.27

# used by the dialog to report available RAM (optional; degrades gracefully)
psutil>=5.9

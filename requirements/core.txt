# SHARED FRAGMENT — NOBODY INSTALLS THIS DIRECTLY.
#
# The geo/raster stack the compute pipeline actually imports, and NO inference
# runtime. Every installable file starts with `-r core.txt` and then adds
# exactly one runtime:
#
#   cpu.txt = core.txt + onnxruntime   (CLI, QGIS plugin venv, any OS)
#   gpu.txt = core.txt + cuda.txt      (NVIDIA CUDA)
#   ci.txt  = core.txt + exact pins    (the CI test image)
#
# That split is not cosmetic. `onnxruntime` and `onnxruntime-gpu` both provide
# the `onnxruntime` module and must never be co-installed, so the file the CPU
# and GPU environments share must not name either of them. Keeping this file
# runtime-free is what makes the mistake structurally impossible instead of a
# thing a comment asks you not to make.
#
# See requirements/README.md for the "which file do I install" table.
#
# Versions are pinned because the golden fixtures are only bit-reproducible
# under this set (see ci.txt).
#
# Pillow is not imported anywhere in this repo; it is a hard dependency of
# scikit-image, pinned here only so fixture reproducibility does not hinge on
# whichever Pillow the resolver happens to pick.
